# 어디까지?

OpenStreetMap Nominatim으로 출발지와 도착지를 검색하고, 두 장소의 좌표를 이용해 직선거리를 계산하는 정적 웹앱입니다. 선택한 장소 사이의 경로는 OpenStreetMap에서 확인할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열거나 로컬 정적 웹 서버를 사용하세요. 별도의 패키지 설치, 데이터베이스, API 키 또는 환경변수는 필요하지 않습니다.

## Vercel 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. Vercel에서 저장소를 Import합니다.
3. Framework Preset은 `Other`로 두고 Build Command와 Output Directory를 비워 둔 채 배포합니다.

서버 함수 없이 정적 파일로 배포되므로 Redis나 환경변수 설정이 필요하지 않습니다.

## 참고

- 거리는 도로 주행거리가 아닌 두 좌표 사이의 직선거리입니다. 지도에서 보기는 OpenStreetMap의 경로 안내를 엽니다.
- 장소 검색은 사용자가 검색 버튼을 누를 때 브라우저에서 Nominatim 공개 API를 직접 호출합니다. 자동완성은 사용하지 않으며, 앱은 검색 요청을 탭 단위로 초당 1회 이하로 제한합니다. Nominatim 서비스 정책에 따라 과도한 트래픽이나 사용 패턴은 제한될 수 있습니다.
- 지도 데이터 및 검색 결과는 OpenStreetMap 기여자가 제공하며, 화면에 저작자 표시 링크를 제공합니다.
